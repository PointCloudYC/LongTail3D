# LongTail3D

## Overview

Industrial point clouds face a unique **dual crisis**: extreme class imbalance (215:1 ratio) combined with systematic **primitive-sharing ambiguity** where safety-critical tail classes (reducers, tees, valves) share identical cylindrical primitives with dominant head classes (pipes).
